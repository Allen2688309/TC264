基于英飞凌 TC264 和逐飞库的智能车应用源码，包含图像处理、整车控制、电机速度闭环、舵机控制、编码器采样及按键处理等模块。

开发环境：AURIX Development Studio（ADS）＋ TASKING 工具链。
仓库结构
TC264/
├─ code/
│  ├─ Beep/             蜂鸣器控制
│  ├─ MyEncoder/        编码器采样与速度反馈
│  ├─ MyKey/            按键与旋转编码器
│  ├─ My_image/         摄像头图像处理
│  ├─ car/              整车运行控制
│  ├─ motor/            电机驱动、速度闭环与差速
│  ├─ servo/            舵机控制
│  ├─ MyHeadFile.h      应用头文件汇总
│  ├─ 复位排查说明.md
│  └─ 本文件夹作用.txt
├─ user/                双核入口与中断服务
└─ .gitignore
控制流程
摄像头采集
    ↓
图像处理与边线提取
    ↓
中线及偏差计算
    ↓
方向控制 → 舵机输出

目标速度与转向量
    ↓
左右轮差速目标
    ↓
编码器速度反馈
    ↓
速度 PI 控制 → 电机 PWM
硬件平台
- 英飞凌 TC264 主控
- MT9V03X 摄像头
- 左右驱动电机及编码器
- 转向舵机
- 按键、旋转编码器及蜂鸣器
使用说明
本仓库为部分应用源码，未包含完整的逐飞底层库、ADS 工程配置、启动文件及链接脚本，不能作为完整工程直接编译。

使用时需要：
1. 准备匹配的 TC264 逐飞库 ADS 工程。
2. 添加所需应用源文件并配置头文件搜索路径。
3. 核对硬件引脚、电机方向、编码器方向及舵机中位。
4. 检查头文件引用和函数调用，补齐依赖。
仓库已移除部分模块，保留源码中可能仍有对应的引用，移植时需要核对，不能仅通过复制目录保证构建成功。
调参建议
- 先确认电机输出方向与编码器反馈方向一致。
- 确认舵机中位、转向方向及机械限位。
- 先调整速度闭环，再调整方向控制和差速。
- 图像参数需要根据摄像头安装位置、光照和赛道调整。
